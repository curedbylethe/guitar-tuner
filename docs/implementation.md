# Implementation plan

1. Initialize strict TypeScript, Vite, reproducible dependencies and baseline shell.
2. Extract notes, presets, relative tuning, state validation and pure domain tests.
3. Extract YIN; cover synthetic signals, stability and automatic-selection hysteresis.
4. Manage microphone and tone ownership, cancellation, suspension and cleanup.
5. Connect the reference UI with typed views and validated persistence.
6. Vendor canonical Aporia CSS; improve mobile Custom workflow without redesign.
7. Verify deterministic audio, permission failures, keyboard and responsive behavior.
8. Add manual-only deployment, validation CI, architecture and contribution documentation.

Reference: supplied guitar-tuner-v2.html. Repository conventions inspected from
curedbylethe/{televim,watch-out-kitty,Aporia}: scoped Conventional Commits,
small independent modules, explicit limitations, focused test commands and
least-privilege workflows. Apache-2.0 follows the actual Aporia LICENSE; its
README's statement that no license was selected is stale.
